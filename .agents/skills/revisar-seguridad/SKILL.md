# Skill: Auditoría Rápida de Seguridad
Cuando se active esta habilidad:
1. Revisa consultas a base de datos para asegurar que usen parámetros preparados y evitar inyección SQL.
2. Verifica validación de entradas en endpoints/formularios y control de autenticación/autorización.
3. Comprueba que CORS, cabeceras y secretos estén correctamente configurados mediante variables de entorno.
4. Entrega un listado breve con los hallazgos ordenados por severidad (Alta, Media, Baja) y cómo corregirlos.
